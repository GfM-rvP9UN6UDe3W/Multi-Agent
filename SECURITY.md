# Security

Please report a vulnerability privately, through [GitHub's private vulnerability reporting](https://github.com/masonlee39/orchvia/security/advisories/new), not in a public issue. Include the version, how to reproduce it and what an attacker could do.

Orchvia runs agents under one local operating-system user and assumes that boundary is trusted; see [concepts](docs/concepts.md) and [status](docs/status.md) for what is and is not verified, including sandbox enforcement. Only the latest release receives fixes.
