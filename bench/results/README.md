# Benchmark results

Each run of [`bench/run.mjs`](../run.mjs) writes one JSON report here, named after its date and kind, for example `2026-09-23-pilot.json`. A report records the command's settings, the model and prices, the machine, the Claude Code version and every request with its tokens, wall time, estimated cost and checks.

No real run has been recorded yet. Reports are committed whether or not they favor Orchvia.
